# Оптимизированный сокращатель ссылок (LFU Cache)

**Выполнили:** студенты группы Идб-25-06 Стогов Ярослав и Чекалин Яков.

Консольное приложение для создания коротких ссылок. Проект реализует алгоритмы кэширования в памяти с автоматическим удалением наименее востребованных данных (LFU).

## 📌 Особенности реализации
1. **ООП дизайн**: Базовая логика инкапсулирована в класс `URLShortener`.
2. **Алгоритмическая сложность**: Поиск короткого и длинного URL работает за константное время **O(1)** благодаря использованию встроенных хэш-таблиц (`dict` в Python).
3. **Контроль памяти**: Лимит хранилища задается конфигурацией при запуске программы. При превышении лимита удаляется ссылка с наименьшим количеством переходов (при равенстве кликов — самая старая).
4. **Интерактивная переадресация**: При переходе по короткой ссылке программа автоматически открывает оригинальный URL в браузере по умолчанию (используя модуль `webbrowser`), параллельно обновляя статистику использования кэша.
5. **Тестирование**: Код покрыт unit-тестами с проверкой граничных случаев (переполнение памяти, логика LFU-вытеснения, проверка счетчиков).

## 🚀 Структура проекта
- `shortener.py` — ядро алгоритма и структуры данных.
- `main.py` — интерактивный CLI-интерфейс пользователя.
- `test_shortener.py` — юнит-тесты.

## 🛠 Запуск проекта и тестов

Проект написан на чистом Python и не требует установки сторонних зависимостей (используется только стандартная библиотека).

**1. Запуск приложения:**
```bash
python main.py
```

**2. Запуск тестов:**

Для проверки корректности работы алгоритма выполните команду:
